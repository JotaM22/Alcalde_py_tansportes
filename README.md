# Proyecto de tesis LPS en Limabamba-Challhuayacu

Proyecto sobre la relación entre el grado de implementación del Last Planner System y la confiabilidad de la planificación semanal durante el mantenimiento periódico del camino vecinal Limabamba-Challhuayacu, Amazonas, en 2026.

## Compilación

Abra `main.tex` como documento principal y seleccione XeLaTeX. Desde la raíz también puede ejecutar:

```bash
latexmk -xelatex main.tex
```

La plantilla usa Times New Roman cuando está disponible y Tinos como alternativa de previsualización.
